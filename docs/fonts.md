# Шрифти Arcanum — факти з реверсу (2025-11-04)

## Формат

- Бітмапні `.art` в `arcanum1.dat: art/interface/*font.art` (33 файли).
- Рендер (tig/font.c): гліф = кадр № `(байт − 31)`; однобайтовий текст.
- Заголовок .art: 132 байти; `num_frames` на зсуві 32; палітри 4×(маркер у заголовку, 256×RGBA після); далі таблиця кадрів 28 Б/кадр (w, h, data_size, hot_x=advance, hot_y, ox, oy), далі пікселі 8bpp (raw якщо data_size==w*h, інакше RLE).
- **У всіх 33 шрифтів рівно 225 кадрів** (символи 31–255) — структурних обмежень нема.
- **У кадрах 128–255 намальована латиниця cp1252** (é, À, ä…) — кирилиці в оригінальній грі НЕМАЄ ніде. Для української: перемалювати кадри під cp1251 (кирилиця 0xC0–0xFF = кадри 161–224) + українські 0xA5 Ґ, 0xAA Є, 0xAF Ї, 0xB2 І, 0xB3 і, 0xB4 ґ, 0xBA є, 0xBF ї.

## Джерело кирилиці (2025-11-04)

Робочий донор: **MORPHEUS.TTF з CyrillicFix** (https://www.wowinterface.com/downloads/info22154-CyrillicFix.html,
cdn.wowinterface.com/downloads/file22154/CyrillicFix.zip) — Morpheus з ru-клієнта WoW.
Містить ПОВНУ українську: і ї є ґ І Ї Є Ґ + кирилиця + латина. Лежить у third_party/ (НЕ в git — ліцензія, див. release-blockers.md).
morph30/morph15 згенеровано з нього; стиль збігається з оригінальним morph. Відома особливість дизайну: «т» має форму латинської t (так і в RU-локалізаціях).
ОНОВЛЕННЯ 2025-11-04 (пізніше): увесь робочий набір (18 interface-шрифтів + системний morph15) перегенеровано з **Forum-Regular (OFL)** — повна українська, найкраща читабельність, ліцензійно чистий для релізу. Morpheus лишився еталоном стилю в third_party/ на випадок майбутньої стилізації. Причина «зникання і» у нечіпаних шрифтах: cp1251 і=0xB3, у cp1252-кадрі там «³».
